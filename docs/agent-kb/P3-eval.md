# P3 检索测试集

按设计第 7 节：**这 15 题在运行任何检索之前写好并提交**（见 git 历史：本文件的第一个提交早于 `P3-report.md` 里的所有检索结果）。题目从本机真实会话里挑，问法按「用户回想时会怎么问」写，不照抄会话里的原话；期望会话不使用 `scratch/p3/agent-test/*` 等测试会话，也不使用本项目自己的开发会话。

每题给两种查询：
- **整句**：把问题原样交给 `--kb-search`（最差情况，Agent 没有提炼关键词）；

指标：期望会话是否出现在返回的**前 5 个会话**里。
