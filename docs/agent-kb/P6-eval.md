# P6 检索测试集：换了说法的 15 题

按任务文件步骤 1a：**这 15 题在运行任何语义检索之前写好并提交**（见 git 历史：本文件的提交早于 `P6-design.md` 和之后所有向量检索结果）。

## 1. 怎么挑的

- 从本机真实库（314 个会话）里挑，只看会话标题和开头几条消息，**没有跑过任何向量检索**。
- 不用 `scratch/` 里的测试会话，不用 AgentKB 自己的开发会话（`claude-code-history-viewer` 目录下的），不用内容涉及私人聊天的会话。
- 与 `P3-eval.md` 的 15 个期望会话**没有重复**。
- 问法的原则：用户回想时不记得原话，用**同义词、口语、描述现象**来问。写完后逐题查了会话消息（user/assistant 文本，`kb.db` 只读副本）里每个"换说法的词"出现了几次，下表"问题里的词在会话里出现吗"一栏列出，保证主要的词是换过的。
- 有几题故意放了**同主题的干扰会话**（备注里写明），检验排序而不只是召回。

## 3. 指标和判定

- 每题期望会话是否出现在返回的**前 5 个会话**里（和 `P3-eval.md` 一样）；同时记名次（第几名，没出现记 0）。
- 对每题的整句和关键词两种问法、关键词 / 向量 / 混合三种模式分别记录，共 6 个数字。
- 题目一旦提交就不改。后续如果发现某题的期望本身不对（例如期望会话不存在），在报告里单独说明，不悄悄换题。

## 4. 对照：原来的 16 题

"不能变差"的对照仍是 P4.1 报告里的 16 道：`P3-eval.md` 的 15 道关键词题 + "电池 耗电"（期望 `a3dc8377`，P4.1 后排第 1）。跑法沿用 `p4-evidence/rank_eval.py`，名次记录的格式也一样。P4.1 的结果：**前 3 名命中 16/16**，"电池 耗电"第 1。混合模式不得低于这个数。
