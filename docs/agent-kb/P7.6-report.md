# P7.6 报告：硬盘备份的 4 处收尾

版本 `0.7.6`（`mod.rs`、`branding.ts`、`fixtures.ts`）。包：`src-tauri/target/release/bundle/macos/AgentKB.app`（ad-hoc 签名，`codesign --verify --deep --strict` 通过；主程序 `Contents/MacOS/AgentKB` SHA-256 `5733cc46ab72421bcf46f1b0cfe082855313f1d157e4076378f25df960cbd672`，61,619,680 字节）。**没有安装。**

## 1. 目标是盘根

- 后端 `backup_dir::effective_root(target, mount)`：目标等于卷挂载点（盘根，比较时忽略末尾分隔符，Windows 忽略大小写）时，实际用 `<根>/AgentKB-backup`。
- 三处使用：保存设置（`save_config` 探测到外置卷且目标是盘根就改写后保存，返回的 config 也是改写后的）；检查磁盘（`test_mirror` 在 `AgentKB-backup` 里建目录和写测试文件）；备份时兜底（`own_folder`，所以 0.7.4 时代已存成 `F:\` 的设置不用重存）。
- `adopt_strays`：本机文件夹（`agentkb-backup.json` 的 id 是本机）留在盘根时，备份前同盘改名挪进 `AgentKB-backup/`。别的电脑的不动；`AgentKB-backup` 里已有同名文件夹时不覆盖；目标不叫 `AgentKB-backup` 时不做。
- 恢复列表 `list`：选盘根时，盘根上的电脑文件夹和 `AgentKB-backup` 里的都列；选 `AgentKB-backup` 时，也列盘根上留着的（Windows 那份）。按路径去重，旧布局的 `kb.db` 只在选到的位置或 `AgentKB-backup` 里算一份。

## 2. 盘名

`volumeLabel.ts::shortVolumeId`：Windows 的 `\\?\Volume{GUID}\` 取花括号里 GUID 的前 8 位，其它原样取前 8 位。`fields.tsx` 用它。

## 3. "已有 109 GB 备份"

`backup_dir::backup_bytes`：只数带 `agentkb-backup.json` 的电脑文件夹、旧布局的 `kb.db`/`kb.db.prev`/`raw`/`notes`；目标本身是电脑文件夹时整个算。盘里其它文件不计。`test_mirror` 的 `existing_bytes` 改用它。

## 4. 恢复别的电脑的备份

`kb_restore_inspect` 返回新增的 `owner`（电脑名、系统、是否本机；旧布局为空）。确认页最上面：
- 别的电脑：红色提示框"注意：这是另一台电脑（名字，系统）的备份"，并写"恢复后，这台电脑的资料库会换成那台电脑的。现在的资料库会先被收起来，不会删除"。只有一份备份直接进确认页时也显示。
- 本机的：一行"本机的备份（名字）"，没有警告框。
- 旧布局：一行"旧版本做的备份，没有记录来自哪台电脑"。
5 种语言都有（`kb.restore.owner.*`）。选择列表里本机原来就标"本机"。

## 测试

- 后端新增 7 个：盘根改写与其它路径保持（`backup_dir`）；本机文件夹挪入、别人的不动、同名不覆盖（`backup_dir`）；恢复列表在盘根和 `AgentKB-backup` 都是两处全列（`backup_dir`）；只统计备份（`backup_dir`）；盘根目标完整备份并挪入旧文件夹，别人的不动（`backup`）；保存设置时盘根被改写（`commands`）；盘根的 `existing_bytes` 只算备份（`probe`）。
- 前端新增 4 个：Windows 盘名与 macOS 盘名（`volumeLabel`）；别的电脑的备份即使只有一份也显示警告；本机备份不报警（`KbRestore`）。
- 7 项检查：tsc、lint、i18n:validate 通过；vitest 1594 通过；`cargo test -- --test-threads=1` 1536 通过、8 忽略；clippy `-D warnings`、`cargo fmt --check` 通过。

## 限制

- 向导（首次设置）提交时不改写盘根目标，靠备份时兜底；设置页保存会改写。
- Windows 只有代码和测试，真机验证（`F:\` 目标、旧文件夹挪入、盘名显示）交给 Windows 侧。
- 备份文件夹里的电脑文件夹仍靠 `agentkb-backup.json` 识别；手工删了 json 的文件夹不会被挪、也不会被列出。
