# P7.4：一块硬盘给多台电脑备份（版本 0.7.4）

## 问题

备份目录写死为 `<硬盘>/AgentKB-backup/`。用户要把同一块硬盘插到 Windows 上做真机验收，Windows 会写进同一个文件夹：`kb.db` 快照被 Windows 的库覆盖（Mac 的快照没了），`raw/` 里两台的文件混在一起，同名文件会被当成"变了"挪到旁边。恢复时就分不清是哪台的。

## 要求

1. 每台电脑一个子文件夹：`AgentKB-backup/<电脑名>-<短 id>/`。id 第一次备份时随机生成，存在本机设置里（不随电脑改名变）；文件夹里放 `agentkb-backup.json`，写 id、电脑名、系统、首次和最近备份时间
2. 写之前核对 `agentkb-backup.json` 的 id 是本机的，不是就不写、报清楚的错，绝不写进别的电脑的文件夹
3. 兼容 0.7.2/0.7.3 的旧布局（`AgentKB-backup/` 下直接是 `kb.db`、`raw/`、`notes/`，没有 json）：本机第一次用新版备份时，**只在旧快照里的来源路径属于本机时**（按 `files.source_path` 判断，快照先拷到本机再打开），把这三样改名挪进本机的子文件夹；判断不了或不属于本机就不动它，另建本机子文件夹，界面提示有一份旧备份
4. 恢复：选到 `AgentKB-backup/` 时列出里面每台电脑的备份（电脑名、系统、最近备份时间、会话数），用户挑一个；直接选到某台的子文件夹也行；旧布局也能恢复
5. 设置页显示本机备份所在的实际文件夹
6. Mac、Windows 都要能用；Windows 那部分只写代码和测试，真机交给 Windows

## 测试

全部在临时目录，不碰真实 `~/AgentKB` 和 `/Volumes/Share`。覆盖：两台（两个不同 id 的临时环境）往同一个硬盘目录备份，互不覆盖；别的 id 的文件夹拒绝写入；旧布局迁移（属于本机 → 挪进去；不属于本机 → 不动）；改电脑名后仍写原来的文件夹；恢复时能列出、能选、旧布局能恢复。
