# 7.1 期：每日整理的三处修正

> 先读 `P7-acceptance.md` 第 7 节、`P7-timezone-findings.md`、`P4` 的验收文件。改的是 Mac 和 Windows 共用的 `kb/digest/`，**两边行为都要对**。版本 `AGENTKB_VERSION = 0.7.1`。

## 1. 要修的

1. **超过 8 条笔记**：AI 给出超过 `MAX_ENTRIES`（8）条时，不再整份判失败。保留前 8 条（其余记一行日志），照常校验和入库。笔记的 prompt 里写明上限的地方核对一遍。加测试：9 条输入得到 8 条，内容和顺序不变
2. **`workspace routing discovery failed`**：在 Windows 上查清是谁报的（Claude Code 还是 Codex，什么条件下）。只读查 AgentKB 自己的日志和 `digest_items.last_error`，**不要读会话原文以外的用户文件和凭据**。先统计 20 个失败里两种原因各几个、引擎和会话大小。能在 AgentKB 这边避开的（例如工作目录、参数、环境变量）就改；改不了的，失败提示改成用户能看懂、知道怎么办的话
3. **时区**：`digest/plan.rs` 候选筛选改成按真实时间比较（见 `P7-timezone-findings.md` 的建议范围），和 `input.rs` 一致；带偏移、`Z`、小数秒、同一瞬间不同写法都要有测试

## 2. 验收

- 7 项检查（Windows 跑；Mac 由 leader 跑）
- 修好后，在用户 Windows 电脑上**只对那 20 个失败会话**重试一次，列出成功几个、仍失败几个及原因、用了多少 token。重试会花用户的 AI 额度，**先告诉用户预计花多少，用户同意后再跑**
- 写 `P7.1-report.md`，推送 `origin/agent-kb-win` 后停下
