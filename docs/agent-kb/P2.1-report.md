## 说明与限制
- 截图仍来自无头 Chromium + 模拟 Tauri IPC，不是真实窗口；语言检测的真实表现需要你首次启动时看一眼（见下）。

## 请你真机看一下
1. 退出正在运行的 AgentKB（装好的新版本在你重新打开时才生效），再打开：左下角应是 `AgentKB 0.2.0`，顶部副标题是新说明。
2. 点首页「立即收集」，等完成后搜索标题里原来的 `Version:` 开头的 Codex 会话，标题应变成你真正的问题。
3. 首页 → 设置：收集频率 10 分钟时，高亮的是「10 分钟」。
4. 新用户语言（可选）：把 `~/Library/Application Support/io.github.moqi777.agentkb/settings.json` 里的 `language` 删掉后重开，应按系统语言显示简体中文。
