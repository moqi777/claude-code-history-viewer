# 从硬盘恢复演练（2026-10-19，Mac，0.7.2）

做法：在临时 HOME 里，把 `/Volumes/Share/AgentKB-backup` 的 `raw/`、`notes/`（跳过 exFAT 的 `._*` 文件）和 `kb.db` 拷到 `<临时HOME>/AgentKB/`，用已安装的 0.7.2 指向临时 HOME 运行。没碰真实 `~/AgentKB`，演练后临时目录已删。

结果：
- 原文：322 个文件，和本机逐个 `cmp` 完全一致，0 缺失
- 笔记：22/22
- 数据库：会话 321（本机 321），消息 89,849（本机 89,855，差的 6 条是快照之后新收集的）
- `--kb-search "go-ios"` 能找到正确会话（关键词模式 8 个会话；本机混合模式 13 个，因为备份里没有语义索引）
- `--kb-show` 能打开会话原文

结论：备份可用，能恢复。

缺的地方：
- 没有恢复按钮，现在只能手动拷三样东西回 `~/AgentKB`（要先退出 App）
- 语义索引（`vectors/`）和模型不在备份里，恢复后要重新下载模型、重建索引
- 设置（`~/Library/Application Support/agent-kb/config.json`）不在备份里，恢复后要重新走一遍设置
