## 4. 真机发现的问题：Esc 把输入框清空（2026-10-17）

用户用拼音打字，拼错时习惯按 Esc 取消这一次组字。现在这一下 Esc 会把输入框里已有的文字全部清空。原因：WebKit 上按 Esc 取消组字时，`compositionend` 先触发，随后的 `keydown` 里 `isComposing` 已经是 false，判断挡不住。

**用户的决定：不要"Esc 清空"这个功能。** 清空靠 ⌘A + 删除，或者点 ✕。

要改：
- 会话搜索和笔记搜索的输入框里，去掉按 Esc 清空的处理；Esc 不再对输入框做任何事
- 测试改成：按 Esc（组字中和不在组字中都试）输入框内容和结果都不变
- 版本 0.6.3（Rust 和前端两处）；7 项检查；重新打包；推送后停下，不要安装到 /Applications
